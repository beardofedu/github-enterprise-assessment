Changelog

User-facing changes to the tool and its documentation. Entries describe project changes, not upstream GitHub product announcements.

Unreleased

Added

  • A user guide covering demo setup, live collection, access, scoring, questionnaire imports, coverage gaps, report exports, and troubleshooting.
  • Real dashboard screenshots using fictional demo data for improvement areas, control filters, questionnaire answers, and coverage gaps.
  • GitHub Actions deployment of this static documentation to GitHub Pages, without publishing local assessment data or running a public assessment server.

Changed

  • The documentation site now uses Primer CSS, the same design system as the dashboard, including automatic light and dark color modes.

This is the first documentation-site changelog entry. Earlier development is available in the commit history; no historical release dates have been inferred.
