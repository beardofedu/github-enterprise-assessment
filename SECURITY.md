# Security Policy

## Supported versions

Please check whether a vulnerability affects the latest code on the `main`
branch. Security fixes are considered for that branch; older versions may not
receive fixes.

## Reporting a vulnerability

Please [report vulnerabilities privately](https://github.com/beardofedu/github-enterprise-assessment/security/advisories/new)
using GitHub's private vulnerability reporting. A GitHub account is required.
Do not disclose vulnerability details in a public issue or pull request.

Include the affected version or commit, steps to reproduce, potential impact,
and a minimal proof of concept when possible. Do not include real credentials,
tokens, enterprise evidence, or other sensitive data.

Maintainers will review the report and coordinate any fix and disclosure
through the private advisory. Response times are not guaranteed.
