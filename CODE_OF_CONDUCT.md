# Code of Conduct

We want this project to be a welcoming place for people of all backgrounds,
identities, and levels of experience.

## Expected behavior

- Treat others with respect and communicate constructively.
- Welcome questions and different perspectives, and be open to feedback.
- Respect people's privacy and obtain permission before sharing their
  personal information.

## Unacceptable behavior

Harassment, discrimination, threats, unwanted sexual attention, personal
attacks, and publishing someone's private information without permission are
not acceptable.

## Scope

This code applies to project spaces, including issues, pull requests, and
other interactions in this repository, and when representing the project.

## Reporting and enforcement

To report behavior or content that violates GitHub's Community Guidelines or
Terms of Service, use [GitHub's abuse reporting tools](https://docs.github.com/en/communities/maintaining-your-safety-on-github/reporting-abuse-or-spam).
Reports sent to GitHub Support go to GitHub and are not automatically shared
with the project maintainers. This project does not list a separate private
maintainer contact for conduct reports.

When maintainers become aware of a concern, they may remove inappropriate
content, limit interactions, or block participants. They will handle concerns
fairly and respect the privacy of those involved.
